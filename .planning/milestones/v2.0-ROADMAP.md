# Milestone v2.0: AI-Assisted SWG Tools

**Status:** ✅ SHIPPED 2026-06-14
**Phases:** 12–16
**Total Plans:** 39

## Overview

v2.0 turns Utinni from a tool that *edits* assets into one that *authors* them, and makes the
whole pipeline AI-drivable. It honors the research-recommended build order: a **hard-gate
revive-feasibility spike first** (Phase 12), then cheap **revive+wrap** of the SOE build CLIs
which also unblocks OT Tier-2 (Phase 13), then the **headless MCP server** centerpiece (Phase 14),
then the meatier **Wave-2 editors** (Phase 15), with the **live-injected MCP bridge + Blender
boundary** explicitly last (Phase 16).

**Locked constraints:** lift-and-shift (copy revive sources + shared libs into a Utinni-owned
`tools/` tree at shared v145; never build in `swg-client-v2`); separate-process headless-first MCP
(net10 stdio shelling `utinni-cli`; never host the SDK in-proc in the x86 client).

## Milestone Summary

**Key Decisions (v2.0):**

- **Lift-and-shift (LOCKED):** revive build tools into a Utinni-owned `tools/` tree at shared v145; never `#include`/ProjectReference into the live `swg-client-v2` tree (it is mid-D3D9→D3D11 migration). Pin an exact source SHA, not a branch HEAD.
- **Separate-process headless-first MCP (LOCKED):** net10 stdio process shelling `utinni-cli`; never host the MCP SDK in-proc in the x86 injected client. The named pipe is the architecture boundary for the live bridge.
- **Coexistence-by-verb-ownership:** BUILD-from-source uses revived compilers (`compile-*`/`build-*`); EDIT-existing-binary uses byte-exact `UtinniCoreDotNet` writers (`roundtrip-*`/`apply-save-*`).
- **Scoped ZERO-verbs exception (Phase 14):** the `apply-save-*` CLI verb family was added to fix the reviewer-confirmed save-no-op — a named, documented exception to "Phase 14 adds zero verbs."
