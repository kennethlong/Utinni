## Overview

V1 shipped in two halves, sequenced "foundations before features". **Half 1 (Phases 1–6)** stabilised
the framework: a CI + Tier-1 C# scaffold landed first as the smallest unlock, then the 15 critical bugs
burned down, then the 8 strategic reworks polished plugin-authoring ergonomics, then the Tier-2 CLI shim
and Tier-1 C++ tests closed the test-harness gap, then a cleanup + open-questions sweep produced the 1.0
framework cut. **Half 2 (Phases 7–11)** delivered the Wave-1 plugin set on top of that stabilised
framework — all five shipping as `IEditorPlugin` subpanels INSIDE The Jawa Toolbox (DEC-C4), not as
separate plugins. V1 shipped when (a) Tier-1 + Tier-2 CI was green with all 15 critical bugs closed and
(b) all five Wave-1 subpanels demoed end-to-end against a live SWG client.

## Milestone Summary

**Key Decisions (v1.0):**

- **DEC-A1..A4 (LOCKED anti-goals):** Utinni is NOT a server-side mod manager / launcher-patcher / Maya-3ds-Max replacement / multiplayer-cheat enabler.
- **DEC-C3 (LOCKED at Phase 4):** pragmatic tiered testing, not blanket TDD — TDD only for pure-logic + file-format layers; native detours + WinForms UI use smoke/integration (Tiers 2-4).
- **DEC-C4 (LOCKED for V1):** the five Wave-1 editors ship as `IEditorPlugin` subpanels inside The Jawa Toolbox, not standalone plugins; shared format code lives next to the panels that consume it. Re-opens for Wave-2/3.
- **CON-O-01..-11:** all 11 inherited + test-harness open questions dispositioned (answered or deferred-with-reason) in `docs/ai/assessment.md`.

**Issues Resolved:**

- All 15 critical bugs (C-01..C-15) closed; DllMain loader-lock (C-01) re-architected to `utinni_init` export + CreateRemoteThread.
- 8 strategic reworks (R-A..R-H): symmetric callback Add/Remove, plugin lifecycle ABI, single-source RVAs, snapshot-iteration dispatch.
- DXSDK June 2010 retired (CON-O-08); LeksysINI replaced by a hand-rolled round-trip INI parser (CON-O-06).
- vcpkg migration (catch2/spdlog/imgui/imguizmo); PlatformToolset v142→v145.

**Technical Debt Incurred (carried into v2.0):**

- RESID-01 OT Tier-2 typed list-param display (closed in v2.0 Phase 13).
- RESID-02 intro-skip scene-transition crash (closed no-repro in v2.0 Phase 12).
- RESID-03 SC3 live-reload candor; RESID-04 window-resize/fullscreen edge cases (addressed in v2.0 Phase 15).
- Phase 09 datatable code-review warnings (7 Warning + 5 Info); loader-lock CI flake (fixed 06-04).
- Tier-3 mock-D3D9 harness deferred; Tier-4 manual residual documented (TEST-04).
