## Trust Boundaries

| GitHub Actions runner (windows-2022) → external CDNs | Runner downloads `actions/checkout@v4`, `actions/cache@v4`, `microsoft/setup-msbuild@v2`, `actions/upload-artifact@v4` from GitHub's action registry, and NuGet packages from `api.nuget.org` over TLS. |
