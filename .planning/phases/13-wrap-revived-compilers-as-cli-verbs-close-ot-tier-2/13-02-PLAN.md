| .tre payload -> disk (RspSynthesizer extract) | Record tree-paths from a .tre are written to disk paths during extraction. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-13-04 | Tampering/EoP | NativeToolRunner Process.Start | mitigate | UseShellExecute=false + explicit arg array (NEVER string-concat into a shell). Acceptance asserts the source has no UseShellExecute=true and no concatenated command string (ASVS V5). |
| T-13-05 | Tampering | RspSynthesizer extract path | mitigate | Extract under a caller-supplied dir only; treat record tree-paths as untrusted — combine via Path.Combine + reject `..`/rooted segments (path-traversal on the extract leg). |
| T-13-06 | Information disclosure | banner/abs-path leak into goldens | mitigate | NormalizeBanner strips `__DATE__`/`__TIME__`/absolute maintainer paths before any committed golden (Pitfall 3) — prevents leaking local paths into the repo. |
