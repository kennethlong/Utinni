| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-13-15 | Spoofing | staged TemplateCompiler.exe resolution for the exporter chain | mitigate | Stage the exporter, tools.cfg, and TemplateCompiler.exe in one controlled dir; set WorkingDirectory explicitly — never rely on ambient PATH (Pitfall 2). |
