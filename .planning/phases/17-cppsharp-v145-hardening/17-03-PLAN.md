<objective>
Build the CPPS-04 ABI gate — the phase's primary engineering work and acceptance gate. Two layers of defense-in-depth catch a binding regen that would silently detonate pre-built plugin DLLs at MEF compose on inject: (a) a per-block-hash ABI diff that ignores CppSharp's reorder churn but trips on a real public-surface change, with a one-command --rebless re-bless path (D-01); and (b) a committed, NEVER-rebuilt-in-CI frozen TJT host plugin DLL that MEF-composes against the freshly-built bindings (D-02). Then rebuild TJT in lockstep against the current surface and re-freeze it as the fixture (CPPS-04 lockstep, cross-repo standing authority).

Purpose: A regen can never silently break the plugin ABI again — the reorder churn no longer hides a real break.
Output: A BCL-only ABI-diff helper + --rebless, a committed block-hash baseline, two xUnit test files, a committed frozen TJT DLL fixture wired as Content, and a lockstep-rebuilt TJT.
</objective>
