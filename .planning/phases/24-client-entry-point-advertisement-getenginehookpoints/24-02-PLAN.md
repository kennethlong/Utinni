<objective>
Populate `s_bindings[]` with the FULL catalog — every `utinni_engine_hookpoints.inc` name minus the
single D-02 carve-out (`consoleHelper::sendInput`) — verifying each bound row's consumer typedef
against the provider's REAL symbol mapping in `utinni_advertise.cpp` (several rows are name-mismatch
corrections that resolve-by-name handles). Then perform the D-04 read→call adaptation: every advertised
accessor-style "global" is a function pointer that CANNOT be `memory::read`, so each consumer read-site
is rewritten to CALL the resolved accessor on the advertised path while keeping `memory::read` on the
SWGEmu RVA path.

Purpose: This delivers EPA-02's full override scope on the advertised client (D-01: bind the full
catalog, not an MVP subset) and closes the read-vs-call semantic gap (Pitfall 4) that would otherwise
read code addresses as data and produce garbage on the advertised client.

Output: complete `s_bindings[]`, the coverage gate's carve-out allow-list, the game.cpp (and any other
accessor-global) read→call adaptations, and a coverage Catch2 unit asserting full resolution.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider symbol map → consumer typedef | A bound row whose consumer typedef does not match the provider's real symbol signature would corrupt the call ABI (the exact failure class this phase exists to kill). |
| accessor pointer → read-site | An accessor function pointer read as data (`memory::read`) returns a code address — garbage values on the advertised client. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-05 | Tampering (ABI corruption) | name-mismatch row signatures | mitigate | Verify each bound row's consumer typedef against `utinni_advertise.cpp`'s real `&symbol`; resolve by NAME; record any signature concern. The name-mismatch rows are signature-checked, not blindly bound. |
| T-24-06 | Tampering (stack corruption, WR-05) | consoleHelper::sendInput | accept (deferred) | Do NOT bind `consoleHelper::sendInput` (D-02): the 3-arg PMF's required recursion-set arg corrupts the stack through the consumer's 1–2 arg typedef. Allow-listed in the coverage gate; cross-repo provider-thunk follow-up filed. Not on the boot/render/scene path. |
| T-24-07 | Tampering (code-as-data read) | accessor-global read-sites | mitigate | D-04 read→call adaptation: every advertised accessor is CALLED, never `memory::read`. Dual-path keeps the SWGEmu `memory::read` only on the absent-export path. |
| T-24-SC | Tampering | npm/pip/cargo installs | mitigate | Not applicable — zero external packages installed this plan. |

No HIGH-severity threats: offline single-user local modding tool, no network/untrusted-input surface.
