## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-02 | Tampering / DoS | TgenDecoder typed field reads | mitigate | Every field read bounds-checks via `IffPayloadCursor.Need` (throws DecoderException(Truncated)); the decoder catches that and raw-falls-back rather than over-reading into the next chunk (Pitfall 5). Acceptance: the raw-fallback test passes for a truncated/malformed leaf. |
| T-20-03 | Tampering | unknown tag / unrecognized version | mitigate | D-02 whole-chunk raw-fallback — the decoder reads the version FIRST and never guesses field offsets for a version it doesn't recognize; unknown tags degrade to {tag, version, hex}, never throw. Acceptance: `TgenRawFallback` test green. |
| T-20-04 | Tampering | DEAD-tag re-emit drift | mitigate | DEAD tags are recognized-and-skipped (display-only), never raw-fallback editable nodes, so they re-emit verbatim via captured-slice and cannot drift bytes (Pitfall 2 / D-03). Acceptance: DEAD-skip test asserts the node is non-editable. |
| T-20-SC | Tampering | npm/pip/cargo installs | accept | No package installs — pure managed, zero new external packages. No legitimacy gate needed. |
