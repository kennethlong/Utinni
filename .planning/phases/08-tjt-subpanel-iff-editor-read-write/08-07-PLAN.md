<objective>
Add the highest-risk save mode (D-05.4): a framework-side `TreWriter` that repacks a `.tre` archive by
full rebuild (the reverse of `TreFile.Parse` + `Inflate`), plus the editor wiring behind a confirm
dialog with an opt-in backup. This is the 8c isolated plan — `.tre` repack has the largest blast radius
(rewrites a shared archive the client loads). The path-CRC risk is sidestepped by preserving each
untouched entry's stored CRC (payload-only edits don't change paths).

Purpose: D-05.4 is a hard V1 must-have (closest to edit-in-place). SWG does NOT support in-place `.tre`
patching (swg-client-v2 reference); the only sanctioned model is loose override (08-05) or full rebuild
(this plan).

Output: `TreWriter.cs` (framework) + its repack byte-compare test (Utinni repo), and
`TreRepackSaveTarget.cs` + `Save ▾` wiring + live smoke (UtinniPlugins repo). Cross-repo plan.

on 08-06 is a FILE-OWNERSHIP dependency, not a logical one: 08-06 (wave 5) and 08-07 (wave 6) both
modify `../UtinniPlugins/.../UI/Forms/FormIffEditor.cs`. Explicit `depends_on` prevents a
depends_on-only scheduler from parallel-executing them and colliding on the same file.
