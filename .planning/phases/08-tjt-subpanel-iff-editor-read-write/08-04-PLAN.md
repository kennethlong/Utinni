Build the editable `FormIffEditor` (a resizable `UtinniForm` via `GetForms()`, per UI-SPEC Host
Placement): the toolbar + tree + leaf-editor layout, leaf payload editing in three modes (editable
hex / inline text / replace-from-file, D-04), the structural tree ops (D-03), and an editor-local
undo/redo stack independent of the scene `UndoRedoManager` (D-08). Per 08-REVIEWS MEDIUM-5, the
controller is PURE-MANAGED and lives FRAMEWORK-SIDE in `UtinniCoreDotNet/Editing/` — not in

the controller reusable by Phases 9-11 via the existing `UtinniCoreDotNet.dll` reference.

Per 08-REVIEWS MEDIUM-6, FormIffEditor overrides `ProcessCmdKey` to capture Ctrl+Z / Ctrl+Y / Ctrl+S
regardless of focused control, sets `ShortcutsEnabled = false` on the hex / text TextBoxes (kills the
built-in WinForms TextBox undo that would otherwise compete with IffEditController), and commits payload
edits to the model on focus-leave (`Leave` / `Validating`) — never per-keystroke (prevents the
per-character undo storm Codex flagged as a unique concern).

Purpose: PROD-W1-IFF Criterion 2 — "view chunk hierarchy, edit chunk content". D-08 keeps IFF edit
history out of CON-M-05's scene-cleanup contract.

Output: `IffEditController.cs` in UtinniCoreDotNet/Editing/, `FormIffEditor.cs`/`.Designer.cs`,

UtinniPlugins. No linked-source path.
