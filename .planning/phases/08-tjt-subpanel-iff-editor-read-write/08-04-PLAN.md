## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user hex/text input -> leaf payload bytes | malformed hex must be rejected with feedback, never silently corrupt the payload |
| Replace-bytes-from-file (arbitrary local file) -> leaf payload | untrusted file content becomes a chunk payload (bounded by writer caps at save) |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

</threat_model>
