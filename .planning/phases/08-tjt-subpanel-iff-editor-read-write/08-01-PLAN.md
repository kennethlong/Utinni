<objective>
Ship the framework-side IFF write primitives (D-01): an `IffWriter` serializer plus a mutable hybrid
DOM (`MutableIffDocument` / `MutableIffNode`) in `UtinniCoreDotNet/Formats/Iff/`, next to the existing
`IffReader`. ALSO introduce the `OpenSource` document-provenance discriminated union (08-REVIEWS HIGH-2)
that 08-04..08-07 consume to gate save modes by the document's origin. These are the foundation every
later Phase-8 plan (CLI round-trip, editor UI, live patch, `.tre` repack) and Phases 9-11 consume.

OpenSource enumerates FOUR sealed cases: `LooseFile`, `TreArchive`, `ClientMemory`, and `Unknown`.
The fourth case (`Unknown`, a sealed singleton via `Instance`) is the degraded-fallback sentinel for
08-05's TRE Browser hand-off when `recordIndex` cannot be resolved from `descriptor.ArchiveLocalOffset`
(per checker W-3 — option (a) explicit sentinel keeps the union exhaustive and type-safe; the existing
`is OpenSource.LooseFile|TreArchive|ClientMemory` pattern-match gates naturally exclude Unknown so
SaveInPlace / Repack / live-patch stay honestly disabled on the degraded fallback).

Purpose: PROD-W1-IFF requires writing IFF chunks back to disk. The D-07 hybrid-DOM design (untouched
leaves re-emit original bytes verbatim) makes Success Criterion 4 ("no corruption of unedited chunks")
structurally near-tautological and preserves the SWG no-pad quirk for free. The `OpenSource` model
closes the cross-AI review's HIGH-2 "design hole" (08-06 live patch + 08-07 repack had no defined source
for `targetAddr` / repack record index) and, with the W-3 `Unknown` sentinel, also closes the post-replan
checker gap about degraded-fallback provenance.

Output: `IffWriter.cs`, `MutableIffNode.cs`, `MutableIffDocument.cs`, `OpenSource.cs` (framework — with
all four cases), their xUnit coverage, and the ROADMAP Criterion 5 wording amendment (D-01 reconciliation).

<!-- Read model the mutable DOM mirrors (UtinniCoreDotNet/Formats/Iff). Build a SIBLING; never mutate these. -->

IffChunk (abstract base): public string TypeId; public int LengthBytes; public string Id; public long OffsetBytes;
  - Id format: "FORM:WSNP/0" (root, ordinal 0); nested "FORM:WSNP/0/FORM:OBJS/3"; leaf "FORM:WSNP/0/DATA:DATA/0"
  - OffsetBytes = byte offset of this chunk's 4-char TypeID header within the document stream (root = 0)
IffLeafChunk (sealed) : IffChunk { public byte[] Data; }   // NOTE: property is Data, NOT Payload
IffContainerChunk (sealed) : IffChunk { public string SubTypeId; public IReadOnlyList<IffChunk> Children; }
  - container TypeId set is exactly { "FORM", "LIST", "CAT " } (trailing space on "CAT " is load-bearing)
IffDocument (sealed) { public IffChunk Root; public IReadOnlyList<IffChunk> AllNodesInPreorder; }
IffReader (static) { public static IffDocument Read(Stream input); public static IffDocument Read(string path); }
  - private const int MaxChunkSize = 64 * 1024 * 1024;  // reuse this cap value in the writer (Security V5)
  - ReadInt32Be: return (b[0]<<24)|(b[1]<<16)|(b[2]<<8)|b[3];  // writer emits MSB-first inverse
