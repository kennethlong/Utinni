Create the `IRenderBackend` seam (the single runtime-polymorphic vtable the overlay will render
through) and the `Dx9Backend` that wraps the existing live-verified `directX::` D3D9 code verbatim.

Plan 02 receives the seam shape rather than discovering it. Also lands the D-07 mock-dispatch Catch2
test (the CI-enforceable proof that all 8 seam members route through the installed backend without a
live device) and wires both new files into the build.

Phase 19 can add `Dx11Backend` behind the same vtable without re-opening the seam.
Output: `render_backend.{h,cpp}`, `RenderBackendSeamTests.cpp`, two `<ClCompile>`/`<ClInclude>` vcxproj
edits. The live D3D9 behavior is UNCHANGED by this plan — it only adds a new, not-yet-consumed seam.
