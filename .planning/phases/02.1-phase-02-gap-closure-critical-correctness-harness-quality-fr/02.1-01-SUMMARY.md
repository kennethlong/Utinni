## Accomplishments

### Task 1: CR-02/CR-03 — widen pCast OUT param + fix UB shift + add test-seam (commit `54e0211`)

- **CR-02 fix:** `pCast` typedef in `network.h` changed from `int64_t(__thiscall*)(swgptr*, int, int)` to `int64_t(__thiscall*)(int64_t*, int, int)`. The OUT param is now an 8-byte slot — safe whether SWG at RVA `0xAA4900` writes 4 or 8 bytes through the pointer. Applies D-06 option c hybrid (default when disassembly unavailable per CONTEXT.md).

- **CR-03 fix:** `Network::cast` parameter widened from `int id` to `int64_t id`. The previous `(id >> 32)` on a 32-bit `int` was UB per C++ [expr.shift]/1. With `int64_t id`, the shift `(id >> 32)` is well-defined. The low/high split uses explicit masks: `static_cast<int>(id & 0xFFFFFFFFLL)` and `static_cast<int>((id >> 32) & 0xFFFFFFFFLL)`.

- **static_assert:** `static_assert(sizeof(int64_t) == 8, "CR-02: networkId slot must be 8 bytes")` added to `Network::cast` body — compile-time enforcement of the OUT param width.

- **Test-seam:** `realCast` shadow variable introduced in `network.cpp`; mutable `cast` pointer reseated from `realCast`. `setCastForTest(pCast fn)` and `resetCast()` implemented in `network.cpp`, declared in `network.h` (`swg::network` namespace). No `#ifdef UTINNI_TESTS` guard (project convention: unguarded test exports per `test_exports.cpp` precedent).

- **Caller compatibility:** `WorldSnapshotReaderWriter::Node::getNodeNetworkId()` calls `Network::cast(id)` where `id` is `int` — implicit widening from `int` to `int64_t` is backward-compatible and correct.

### Task 2: WR-01/WR-09 — real harness + drop CoInitializeEx (commit `56725af`)

- **WR-01 real harness:** `utinni_test_networkCast` in `test_exports.cpp` rewritten with function-pointer reseat pattern:
  - `testCastDouble` (declared `static int64_t __thiscall testCastDouble(int64_t* networkId, int, int)`) writes sentinel `0xDEADBEEFCAFEBABELL` through the `int64_t*` OUT param. The upper 32 bits (`0xDEADBEEF`) differ from the lower 32 bits (`0xCAFEBABE`) — truncation to a 4-byte slot is detectable.
  - The export calls `setCastForTest`, invokes `Network::cast`, then calls `resetCast`.
  - `network.h` added to `test_exports.cpp` includes.

- **NetworkCastTests.cs rewritten:** Old tautological test (`ReturnsInitializedValue` asserting hardcoded `0xDEADBEEF`) replaced with `NetworkCast_WithTestDouble_ReturnsFullSentinel` asserting `unchecked((long)0xDEADBEEFCAFEBABEL)`. The test fails if CR-02 is reverted (swgptr* 4-byte slot loses upper 32 bits of sentinel).

- **WR-09 fix:** `CoInitializeEx(nullptr, COINIT_APARTMENTTHREADED)` at `utinni.cpp:140` removed. CLR host uses `CLRCreateInstance` (free-threaded; no STA required). Comment documents the rationale and confirms no downstream COM consumer. The utinni_init thread exits after `return 0`; the abandoned apartment imbalance is eliminated by dropping the call entirely (no `CoUninitialize` was ever added — drop-both approach per RESEARCH §WR-09).
