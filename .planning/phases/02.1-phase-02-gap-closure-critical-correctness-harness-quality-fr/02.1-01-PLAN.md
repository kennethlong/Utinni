<objective>
Close CR-02, CR-03, and WR-09 from the Phase 02 code review.

CR-02: `pCast` declares its OUT param as `swgptr*` (4 bytes). If SWG writes an 8-byte NetworkId through that pointer it stomps 4 adjacent bytes of the caller stack. Apply the D-06 option (c) hybrid: widen OUT param to `int64_t*`, widen `networkId` local to `int64_t`. Safe whether SWG writes 4 or 8 bytes.

CR-03: `(id >> 32)` on a 32-bit `int` is UB per C++ [expr.shift]/1. Widening `Network::cast`'s parameter to `int64_t` (per option c) makes the shift well-defined — the high/low split becomes explicit and correct.

WR-09: `CoInitializeEx(nullptr, COINIT_APARTMENTTHREADED)` in `utinni_init` has no COM consumer downstream (grep confirmed 0 `CoCreateInstance` / `CoTaskMemAlloc` calls in UtinniCore; CLR host uses `CLRCreateInstance`, which is free-threaded and does not require COM apartment init). The call is simply dropped — cleaner than pairing with `CoUninitialize` on a thread that exits immediately after `return 0`.

Per D-04, every finding gets a regression test. CR-02/CR-03 share the WR-01 real harness shape (which is the subject of Plan 02.1-03, Wave 3). This plan delivers the C++ fix and the test-seam infrastructure that Plan 02.1-03 depends on. The NetworkCastTests rewrite lands here alongside the C++ changes (Task 2), so the tests go RED immediately, then GREEN after the fix in the same commit.

Purpose: Close three native-correctness findings that survived Phase 02's fixes.
Output: Updated network.cpp, network.h, utinni.cpp; new NetworkCastTests harness; assessment.md updated.
</objective>
