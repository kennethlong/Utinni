## Accomplishments

### Task 1: WR-01 — real NetworkCast harness via __declspec(naked) ABI-shim (commit `7c0aac1`)

**Background:** Plan 02.1-01 attempted a `static int64_t __thiscall testCastDouble(...)` but MSVC C3865 blocks `__thiscall` on free functions. The setCastForTest/resetCast seam was left in place for this plan.

- **testCastDoubleNaked** (`__declspec(naked)`) implements the `__thiscall` ABI in inline asm:
  - ECX = `int64_t*` networkId (OUT param, 8-byte slot)
  - Writes `0xDEADBEEFCAFEBABE` through ECX: `[ecx]=0xCAFEBABE`, `[ecx+4]=0xDEADBEEF`
  - Returns same sentinel in EAX:EDX pair (low/high halves)
  - `ret 8` callee-cleans 2 explicit stack args (low + high = 8 bytes)
- **utinni_test_networkCast** rewritten:
  1. `setCastForTest(reinterpret_cast<pCast>(testCastDoubleNaked))` — reseats the real call path
  2. `utinni::Network::cast(id)` — calls through the real chain in network.cpp (which invokes `swg::network::cast(&networkId, low, high)`)
  3. `resetCast()` — restores to realCast pointer
  4. Returns networkId value (the OUT-param sentinel)
- **NetworkCastTests.cs** updated:
  - Old: `Assert.Equal(unchecked((long)0xDEADBEEFL), result)` (tautological 32-bit sentinel)
  - New: `NetworkCast_WithTestDouble_ReturnsFullSentinel` asserts `unchecked((long)0xDEADBEEFCAFEBABEL)`
  - Regression: CR-02 revert (4-byte slot) truncates upper 32 bits → test fails. CR-03 revert (UB shift) corrupts high half → test fails.

### Task 2: WR-02 — Marshal.AllocHGlobal cross-heap harness (commit `d74949a`)

**Heap probe result (Concern A):** UtinniCore.vcxproj Release|Win32 has no `<RuntimeLibrary>` entry → default `/MT` (static CRT). Modern MSVC v142 `/MT` routes `new[]`/`delete[]` through `_malloc_base` → `GetProcessHeap()`. `Marshal.AllocHGlobal` also uses `GetProcessHeap()`. **Same heap = PARTIAL-PROOF** in Release.

- **ConfigBufferFreeTests.cs** updated:
  - Replaces `GCHandle.Alloc(buf, GCHandleType.Pinned)` with `Marshal.AllocHGlobal(16)` (genuine OS heap pointer)
  - `finally { Marshal.FreeHGlobal(osHeapBuffer); }` ensures correct ownership cleanup
  - PARTIAL-PROOF note documented in class XML doc: in Debug (`/MTd`) the CRT and OS heaps ARE distinct → `delete[]` on HeapAlloc pointer fires `_ASSERTE(_BLOCK_TYPE_IS_VALID)` → test would catch a regression
  - Follow-up item: Phase 6 STAB-03 to add `Utinni.CrossCrtFreeFixture.vcxproj` with `/MD` linkage for full Release-build cross-heap proof
