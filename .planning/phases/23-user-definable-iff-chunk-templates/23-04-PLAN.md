## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-23-04-ALT | Tampering | altitude gate bypass | mitigate | Gate on root-FORM built-in sub-type FIRST (reuse DecodeIffCommand's set); a template can never engage on a built-in-claimed file (D-05). Override path is explicitly DEFERRED. |
