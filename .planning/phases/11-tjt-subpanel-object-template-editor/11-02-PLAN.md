    - Cyclic DERV (A→B→A) or depth beyond the cap: resolution terminates via the visited-set/depth guard, surfaces the remainder as unresolved, never stack-overflows.
    - Breadcrumb chain reflects root→…→this with each segment's resolution state.

DERV-CHAIN DEPTH/CYCLE GUARD (NEW — the single new defensive control per RESEARCH Security Domain): maintain a visited-set of resolved base names plus a hard depth cap (e.g. 64); on revisit or cap-exceed, stop recursing and mark the remaining chain unresolved. Produce a `Breadcrumb` (ordered ancestor names root→this) with per-segment resolution state.

Add both files to `UtinniCoreDotNet/UtinniCoreDotNet.csproj`. Resolution is pure-managed and reads through the existing `TrePayloadResolver` path-traversal defense — do not weaken it.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DERV base name → TRE resolution | A malicious/cyclic DERV base name crosses into cross-IFF resolution; could traverse paths or recurse without bound |
| ancestor `.iff` bytes → decoder | Untrusted base-template payloads (possibly malformed) are parsed during the chain walk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04 | DoS | Deeply-recursive or cyclic DERV chain → stack overflow | mitigate | NEW depth/cycle guard in `ObjectTemplateResolver` (visited-set + hard depth cap); regression-tested by the cyclic-chain [Fact] |
| T-11-05 | Tampering / Elevation | Path traversal via a hostile DERV base name resolving outside the archive base dir | mitigate | Resolution goes exclusively through `TrePayloadResolver.TryResolve`, which already rejects `..`/rooted tree-file names and enforces master-index containment — do not bypass it |
| T-11-06 | DoS | Encrypted/enumerate-only (V6000) base treated as an error path | accept | `TryResolve` returns false → D-01 graceful degradation renders "unresolved base"; no decrypt attempted (RESEARCH V6 Cryptography = no) |
