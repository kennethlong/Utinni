<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TRE entry / IFF document → editor open | A user-selected entry (possibly enumerate-only/malformed/non-OT) crosses into the OT editor via hand-off |
| WinForms event thread ↔ background resolve | Chain resolution runs off-UI-thread and marshals back; a thrown resolve must not crash the UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-08 | DoS / Tampering | Hand-off opens a non-OT or enumerate-only entry → parse failure / blank editor | mitigate | Content-gate on `LooksLikeObjectTemplate` + `TryResolve` false-return → status message, never a throw into the UI (mirrors Phase 9 hand-off); unresolved-base degradation (Plan 02) keeps the open non-blocking |
| T-11-09 | Denial of Service | A thrown exception during background resolve crashes the editor window | mitigate | Marshal resolve results via BeginInvoke and surface failures as status copy; Plugin.cs registration is in try/catch so a construction failure disables the editor, not the whole plugin (SPI preserved) |
| T-11-10 | Tampering | Widening the MEF SPI breaks STAB-04 preserved foundations | mitigate | GetSubPanels() stays `return null`; the form is found by type via GetForms() — verified by the grep gate |
| T-11-SC | Tampering | npm/pip/cargo installs | accept (N/A) | No packages installed this plan |
| — | S/R/I/E (auth/session/network) | — | accept (N/A) | Local WinForms editor; no auth/session/network surface |
</threat_model>
