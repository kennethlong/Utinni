<objective>
Ship the framework-side typed object-template format core (CF-01): a self-describing param value codec, a mutable model over Phase 8's `MutableIffDocument`, and a byte-exact writer. This is the only genuinely-new read/write infrastructure Phase 11 adds — everything downstream composes on it.

Purpose: Object templates ARE IFF, so byte-exactness is free from `MutableIffDocument`/`IffWriter` (the Phase 9 datatable lineage). The new work is decoding the per-param self-describing data-type tag into typed scalars (with a defensive hex fallback) and a mutable param-chunk model that keeps the machine-managed count in lockstep.
Output: `UtinniCoreDotNet/Formats/ObjectTemplate/` core types + the single `ReadInt8` cursor helper + Wave-0 unit tests.
</objective>
