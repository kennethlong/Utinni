rename key; id machine-managed per D-01) is the model layer the editor drives.

10-03). 10-02 (CLI roundtrip-stf golden gate) consumes this public API; 10-03 (editor shell) consumes

10-04 (bulk), and 10-05 (save) all compose on. Bundling reader+model+writer+controller in one plan
keeps the context cost tractable (mechanical, single flat format, no per-type cells, no cascade) and
surfaces the byte-exactness + name-validation port risk at the earliest point.

    - StringTableDocument.FromBytes(byte[] data): reads magic 0xABCD (u32 LE; reject otherwise with StringTableParseException), version byte (accept 0 and 1, reject others), nextUniqueId (u32), count (u32, forged-count guarded against remaining bytes exactly as StringTableDecoder does). Reads `count` string entries (id u32, sourceCrc u32, charCount u32 bounded by remaining/2, UTF-16LE text via Encoding.Unicode replacement fallback — U+FFFD, never throws on malformed code units per STAB-03). Reads name entries (id u32, length u32 bounded, ASCII name) UNTIL the name block is exhausted; tolerates a string-only table with NO name block (mirror StringTableDecoder's `Remaining < 8` break) AND a PARTIAL name block where nameMap.size() < count (F4b read behavior: entries with no matching name row are left name-less — the decoder TOLERATES them). Joins id→name. NULL-NAME ENTRY POLICY (F9): the DECODER tolerates name-less entries, but the LOADED MutableStringTableDocument REJECTS-AT-LOAD-WITH-WARNING when any entry has no name (surface a "corrupt string table — a save will normalize it" warning to the caller / status strip) rather than silently exposing id-only rows; record this as the chosen default in the SUMMARY. (If a future need for id-based remove arises it can be added; for V1 the reject-at-load-with-warning default keeps the editable surface name-keyed.) PER-ENTRY ORIGINAL-BYTES CAPTURE: for each string entry capture the exact [id..end-of-text] byte slice into the corresponding MutableStringTableEntry so an untouched entry re-emits verbatim; ALSO capture the FULL original whole-file byte[] for the F2a zero-dirty short-circuit.
