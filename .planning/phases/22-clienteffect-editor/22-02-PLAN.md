    Field edits:   --field <name>  --value <new value>   (variable-length string edits + scalar/flag/color edits — the fixed-length guard is REMOVED).
    List mutation: --add-command <CPAP|PSND|CLGT|CAMS|FFBK>  (emits at the file's existing version, D-03)
                   --remove-leaf <stableId>
                   --reorder <stableId> <up|down>
  Exactly ONE mutation per invocation (field edit XOR add XOR remove XOR reorder); reject combinations with exit 1.
- decode-effect / decode-iff CLEF JSON envelope: follow the particle/terrain `BuildXxxResult` JObject conventions (rootType "CLEF", version, rawPreserved, an ordered commands array of {index, tag, isRaw, fields}). Keep it descriptive (read tool); no byte dumps.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arg `--root` + relAsset → loose-override save target | An attacker-controlled or mistyped path could escape the intended client-root directory (path traversal). |
| untrusted `.iff` bytes → `decode-effect` / `roundtrip-effect` / `apply-save-effect` | A malformed/forged CLEF file crosses into the codec from the CLI. |
| MCP client → `summarize_clienteffect` → subprocess | A relative path from an MCP caller must not escape the MCP `ResolvedRoot`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-path | Tampering / Elevation | `apply-save-effect` save target | mitigate | Resolve the destination only through `LooseOverridePath.Resolve(root, relAsset)` (fail-closed: rejects null/empty, rooted paths, any `..` segment, prefix-match escapes; final ordinal-ignore-case `StartsWith(root + sep)`). A rejected path returns exit 2 `PathContainment` with NO write. Asserted by `ClefLooseOverrideTests`. |
| T-22-halfunderstood | Tampering | `apply-save-effect` field edit on a raw/non-editable leaf | mitigate | Reject the edit before any write when the addressed command is raw-fallback / unknown-tag / truncated (mirrors `ApplySaveTrnCommand`'s `TargetTypedNodeIsEditable` gate, RESEARCH § Security Domain #4). Exit 1; never rewrites a half-understood payload. |
| T-22-malformed | Denial of Service | all three verbs decoding | mitigate | The codec's `IffPayloadCursor` bounds-checks + raw-fallback (from Plan 01) means a malformed file surfaces as a caught parse exception → exit 2, never an unhandled throw. Generic `Exception` is intentionally NOT caught (the locked contract) so a true bug is loud, but every expected malformation is a typed catch. |
| T-22-mcp-escape | Tampering / Information Disclosure | `summarize_clienteffect` path | mitigate | The MCP `ResolvedRoot.Resolve(relativePath)` (T-14-01) rejects path escape before the subprocess shell; the tool passes only the resolved absolute path to `utinni-cli`. ZERO format logic in-process keeps the attack surface at the proven CLI boundary. |
| T-22-SC | Tampering | npm/pip/cargo/NuGet installs | accept | No external packages are installed this phase (RESEARCH § Package Legitimacy Audit: N/A — pure-managed composition of in-repo assemblies). No slopcheck surface. |
</threat_model>
