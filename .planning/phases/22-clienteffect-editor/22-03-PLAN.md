<convention_decision>
<!-- Mirrored by apply-save-effect (Plan 02), which owns its OWN copy of the flag. Documented here so both verbs match. -->
The CLI `apply-save-*` verbs each compose the loose-override base as `<root>/loose/` to match the
in-app editor and every other editor (IFF/Datatable/STF/OT). Add an OPTIONAL `--loose-subdir` flag
(default `"loose"`) to `apply-save-trn` so the CLI lands at `<root>/loose/<relAsset>`. Empty string
preserves the legacy `<root>/<relAsset>` (back-compat for any caller that pre-composes `loose/`).
The two-step resolve mirrors `TerrainSaveTargets`: `base = Resolve(root, looseSubDir)` then
`Resolve(base, relAsset)` — both legs fail-closed. `apply-save-effect` (Plan 02) defines the SAME flag
and default IN ITS OWN command (REVIEWS HIGH #3 — self-contained per verb, no cross-plan dependency),
keeping the matrix consistent (D-10).
</convention_decision>
