<convention_decision>
<!-- Shared with apply-save-effect (Plan 02). Documented here so both verbs match. -->
The CLI `apply-save-*` verbs compose the loose-override base as `<root>/loose/` to match the in-app
editor and every other editor (IFF/Datatable/STF/OT). Add an OPTIONAL `--loose-subdir` flag
(default `"loose"`) to `apply-save-trn` so the CLI lands at `<root>/loose/<relAsset>`. Empty string
preserves the legacy `<root>/<relAsset>` (back-compat for any caller that pre-composes `loose/`).
The two-step resolve mirrors `TerrainSaveTargets`: `base = Resolve(root, looseSubDir)` then
`Resolve(base, relAsset)` — both legs fail-closed. `apply-save-effect` (Plan 02) uses the SAME flag
and default, keeping the matrix consistent (D-10).
</convention_decision>
