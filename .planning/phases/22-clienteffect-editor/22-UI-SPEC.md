# Phase 22 — UI Design Contract

> Visual and interaction contract for the **ClientEffect Editor** (`EffectsSubPanel` →
> `FormClientEffectEditor`). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Platform reality (read first):** This is NOT a web/mobile frontend. The deliverable is a
> **.NET Framework (net4.7.2) WinForms** editor that ships *inside* **The Jawa Toolbox** (TJT) — an
> injected SWG modding tool. There is no HTML/CSS, no browser, no component library, no design-token
> JSON, no responsive breakpoints. The "design system" here is the **established TJT editor visual
> language** already shipping in the repo (`Colors` dark theme, Segoe UI 8.25pt base, 4px-grid spacing,
> the `TerrainSubPanel`→`FormTerrainEditor` and `FormParticleEditor` precedents). Every dimension below
> is expressed in WinForms terms (Controls, Docking, SplitContainer, ListView/DataGridView,
> dock/z-order rules, state/feedback copy) and is a **house-style conformance constraint**, not a new
> palette/scale to invent. Where a web template dimension is genuinely N/A for a native desktop editor,
> it is marked N/A with a one-line reason.
>
> **Form factor (LOCKED, CONTEXT D-04/D-05):** a **thin docked `EffectsSubPanel : SubPanel`**
> (`IEditorPlugin`, registered via the `SubPanelContainer("Controls", …)` array, pinned to 417px) that
> **launches a roomy standalone `FormClientEffectEditor`** (singleton, hide-not-dispose). The
> `TerrainSubPanel`→`FormTerrainEditor` idiom exactly. The flat command list + per-command field grid
> wants horizontal room the 417px docked panel can't give, so the heavy editing surface lives in the
> Form. Scope is **ClientEffect-only** — the name leaves room for a future Lightning/Swoosh container
> but **no speculative multi-format seams ship this phase** (D-05, YAGNI).

## Design System

| Property | Value |
|----------|-------|
| Tool | none (WinForms desktop; shadcn N/A — not a React/Next/Vite project, so the shadcn init gate does not apply) |
| Preset | not applicable |
| Component library | none — `System.Windows.Forms` + existing TJT shared controls (`UtinniLabel`, `UtinniButton`, `UtinniContextMenuStrip`, `ThemedDataGridView`, `UtinniForm`, `FormSaveConfirmDialog`, `FormParamHexEditor`) under `UtinniCoreDotNet.UI.*` / `TJT.UI.Controls` |
| Icon library | none — text labels + glyph chars only (the IFF/Particle-editor `●` dirty-marker precedent); no icon font, no SVG |
| Font | **Segoe UI 8.25pt** (the WinForms `Form.Font` default TJT inherits); **`Consolas` 9pt** is the monospace exception for raw-byte / hex regions only (`FormParticleEditor` `MarkRawPreservedRow` precedent) |

**Theme source of truth:** `UtinniCoreDotNet.UI.Theme.Colors` (dark theme active). Do NOT hard-code
ARGB literals — call `Colors.Primary()` / `Colors.PrimaryHighlight()` / `Colors.PrimaryShadow()` /
`Colors.Secondary()` / `Colors.Font()` / `Colors.FontDisabled()` so a theme flip stays centralized
(`FormParticleEditor`/`TerrainSubPanel` precedent). `System.Drawing.Color.Red` is the **sole** allowed
raw color literal, reserved for failure-emphasis status text.

## Spacing Scale

WinForms is pixel-positioned; TJT panels lay out on a **4px base grid** (`TerrainSubPanel.BuildContent`
uses 4px insets, 22px button height, 30px Bottom-footer; `FormParticleEditor` uses a SplitContainer +
4px-grid toolbar). Multiples of 4 only.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Control inset (`Location` x/y = 4), splitter width, accent-rule height (2px is a sub-grid exception, see below), grid base unit |
| sm | 8px | Compact control gap, `Panel.Padding = 8` |
| md | 16px | Command-row pitch in the field grid, control-group vertical gap |
| lg | 24px | Labeled-group separation / section band region |
| xl | 32px | Major sub-section break inside the Form body |
| 2xl | 48px | (reserved — rarely needed) |
| 3xl | 64px | (reserved — rarely needed) |

**Exceptions (documented house-style, not new grid values):**
- **2px accent rule** above the docked-panel banner (`TerrainSubPanel` `pnlBannerAccent` Height = 2) — a
  sub-grid decorative rule, the one authorized value below 4.
- **22px** control height for `UtinniButton` rows and the banner label (`TerrainSubPanel` precedent — an
  8.25pt line needs ~18–22px; treat 22 as the established control-row height).
- **30px** `Dock.Bottom` footer strip height (`TerrainSubPanel` `lblFooter`).
- `SplitContainer.Panel1MinSize` / `Panel2MinSize` collapse-guards (set a sensible min on each pane so a
  drag can't starve the list or the field grid) — guard minimums, not layout spacing.
- Touch-target sizing does not apply (mouse-only injected desktop tool).

## Typography

WinForms `Font` objects, not CSS — there is no line-height ratio token (WinForms auto-manages line
metrics; multi-line copy uses `AutoSize = false` fixed-height labels so the dock layout stays stable).
The TJT house rule (`TerrainSubPanel` line 134; `FormParticleEditor` line 179): **base 8.25pt regular
for everything; Bold is reserved**; color/position differentiates roles instead of weight. Exactly the
constrained set below.

| Role | Size | Weight | Notes |
|------|------|--------|-------|
| Body / field value / command-list row | 8.25pt | Regular | List rows, field labels, field values, status copy. The default `Form.Font`. |
| Banner / section title | 8.25pt | **Bold** | The ONE authorized Bold use — the docked-panel banner ("Effects") and the Form title band; differentiated further by the 2px `Colors.Secondary()` accent rule above it. |
| Disabled / hint / candor label | 8.25pt | Regular | Hints, the DEC-A3 candor footer, the honest-disabled Preview reason, the raw-fallback hint — rendered in `Colors.FontDisabled()`, not a different size. |
| Monospace (raw bytes) | 9pt `Consolas` | Regular | Raw-fallback hex peek for unknown command tags / unknown CLEF versions + any byte-offset readout only (the documented monospace exception; `FormParticleEditor` `MarkRawPreservedRow` verbatim). |

**Hard rule:** no third font family, no italics, no size beyond {Segoe UI 8.25pt, Consolas 9pt}. Bold
only on the banner/section title.

## Color

The TJT dark theme is a fixed 3-role palette from `Colors` (verified against
`UtinniCoreDotNet/UI/Theme/Colors.cs`). Map directly to the 60/30/10 model — these are **conformance
values**, sourced from `Colors.*`, never new hexes.

| Role | Value | Source | Usage |
|------|-------|--------|-------|
| Dominant (~60%) | `#282828` (40,40,40) | `Colors.Primary()` | Panel/Form background, toolbar, status strip, all surface fills |
| Dominant variant | `#404040` (64,64,64) | `Colors.PrimaryHighlight()` | Command-list and field-grid control backgrounds (the inset content wells) |
| Dominant shadow | `#191919` (25,25,25) | `Colors.PrimaryShadow()` | Grid column-header band, recessed strips |
| Secondary text (~30%) | `WhiteSmoke` / `#646464` | `Colors.Font()` / `Colors.FontDisabled()` | Primary text in WhiteSmoke; hints/disabled/candor in FontDisabled gray (100,100,100) |
| Accent (~10%) | `#007ACC` (0,122,204) | `Colors.Secondary()` | RESERVED — see list below |
| Destructive / error | `Color.Red` | `System.Drawing.Color.Red` | Error/failure status text ONLY (`FormParticleEditor` `SetFailure` precedent: red `lblStatus` on parse/save failure) |

**Accent (`Colors.Secondary()` #007ACC) reserved EXCLUSIVELY for:**
1. The **2px accent rule** above the docked-panel banner and the Form title band.
2. The **dirty / unsaved-changes marker** — the `●` glyph + `lblDirty` tint (`FormParticleEditor`
   `lblDirty.ForeColor = Colors.Secondary()` precedent). When a command's fields have an uncommitted
   edit, OR a command was added/removed/reordered, the dirty marker shows.
3. The **brief Preview-pulse** on the reload-candor badge (`FormParticleEditor.PulseReloadBadge` — a
   1-second tint that returns to `Colors.Font()`), used ONLY on the live-capable path (which is
   unreachable this build — see Copywriting/Preview).

Accent is **never** used for "all buttons," general selected-row highlight (that uses the grid's native
themed selection), or decorative emphasis. Edits are signaled by the dirty `●` marker, not by recoloring
whole controls.

**Live-preview / reload tier is signaled by COPY + a neutral/gray/red color, never a green "success"
hue** — there is no green token in the theme, and D-07/Pitfall 3 forbid over-promising. The honest
degraded tier uses `Colors.FontDisabled()` (dimmed, reads as candor not error); the no-client tier uses
`Color.Red` only when surfaced as a true failure. The live-capable "Re-triggered" copy exists in the
seam but is unreachable this build (`IsRetriggerHookReachable()` hardcoded `false`).

## Copywriting Contract

All copy is desktop micro-copy on labels, buttons, tooltips, and confirm dialogs. The **reload-candor /
Preview vocabulary is LOCKED** — carried over verbatim from the shipped `FormParticleEditor` (the D-07
reuse target) so the ClientEffect Preview is *identically honest*. Do NOT soften or invent new wording.
Keep these as `private const string` so the grep gates can verify them verbatim and a future edit can't
silently soften them (`FormParticleEditor`/`TerrainSubPanel` precedent).

| Element | Copy |
|---------|------|
| Primary CTA (commit to disk) | Button label **"Save"** — writes the loose-override `.iff` under `<root>/loose/` (D-10). The Save▾ drop-down (Particle-editor shape) offers **"Save (in place)"** (loose-file source only), **"Save as loose override"**, and **"Save As…"**. When opened read-only from the TRE Browser, in-place is disabled (TREs are never edited in place — D-09). |
| Secondary action (iterate) | Button label **"Preview in client"** — see the honest-disabled contract below (D-07). |
| Open entry (from TRE Browser) | Context action **"Open in Effects Editor"** on a CLEF `.iff` TRE entry → opens read-only (the `CollapsiblePanel.WrappedSubPanel` hand-off, D-09). |
| Open entry (loose override) | Docked-panel button **"Open ClientEffect Override…"** → file picker for an existing loose-override `.iff` (the host owns the dialog; the thin panel is a pure launcher). |
| Docked-panel launch button | **"Open Effects Editor"** (launches the singleton `FormClientEffectEditor`). |
| Empty state heading | **"No effect loaded"** |
| Empty state body | **"Open a ClientEffect .iff from the TRE Browser, or open an existing loose override, to view and edit its command list."** |
| No-selection (list shown, no command picked) | **"Select a command to view its fields."** |
| Empty command list (valid CLEF, zero commands) | **"This effect has no commands. Use Add command to insert one."** |
| Raw-fallback field hint (unknown command tag) | **"This command isn't typed yet — its original bytes are preserved exactly and saved unchanged."** (verbatim from `FormParticleEditor` `RawPreservedTooltip`; degrade-not-fail per D-06 / D-13) |
| Unknown-version banner (whole CLEF raw-preserved) | **"Unrecognized ClientEffect version `<v>` — preserved as original bytes; fields are read-only."** (`FormParticleEditor.LoadDocument` raw-preserved status precedent) |
| Version-locked field hint (D-03) | **"This effect is version `<vNNNN>` — only the fields that version defines are shown. The version is preserved on save."** (shown when a CPAP command exposes fewer fields than v0003) |
| **Preview — honest disabled state (THIS BUILD, D-07 + RESEARCH finding #2)** | The button is **ENABLED whenever a doc is open** but performs **NO retrigger** (WinForms renders no tooltip over a disabled control, so the candor must be reachable — `FormParticleEditor` B6/15-19 fix). On click with no reachable hook: surface, in `Colors.FontDisabled()` on the status strip, **"Live preview isn't wired this build — edits show on the next scene change or relog."** Tooltip (no-hook, running): same string. Tooltip (no client): **"No live client — start SWG to preview in-scene."** The two reasons stay DISTINCT. NEVER imply a reachable hook. |
| Preview — live-capable copy (seam-only, unreachable this build) | Status **"Re-triggered live effect."** in `Colors.Font()` + the 1s accent pulse — gated behind `Game.IsRunning && IsRetriggerHookReachable()`, which is `false` this build. Kept in the seam for the future native hook (D-08); MUST NOT be reachable until the hook lands. |
| Save success | Status **"Saved → `<override-path>`"** in `Colors.Font()`. |
| Save failure / path-escape | Status **"Save failed: `<reason>` — your edits are kept in the editor."** in `Color.Red` (e.g. `--root` containment rejection, D-10). |
| Add command | Toolbar/context label **"Add command"** → a small picker of the 5 known tags (CPAP / PSND / CLGT / CAMS / FFBK), emitting at the file's existing CLEF version (D-03). |
| Remove command | Toolbar/context label **"Remove command"** (enabled only with a command selected). |
| Reorder | Toolbar/context labels **"Move up"** / **"Move down"** (cosmetic per SOE — no timing semantics — but offered, D-02). |
| DEC-A3 preview-scope footer (dimmed) | **"Preview is live in the real SWG client — Utinni never renders effects itself."** (DEC-A3 candor; dimmed `Colors.FontDisabled()` footer, `TerrainSubPanel` `DecA3Footer` shape) |

**Destructive actions:** The list-authoring affordances (add / remove / reorder) and field edits are
all **editor-local and undoable** via the editor-local undo/redo seam (`FormParticleEditor`
`undoStack`/`redoStack` precedent, `Ctrl+Z`/`Ctrl+Y`); saves write a *loose override* (the source TRE is
never mutated, D-09). So there is **no inherently destructive in-editor action**. Two confirm cases:

| Action | Confirmation |
|--------|-------------|
| Discard unsaved edits (Open another / close while dirty) | `FormSaveConfirmDialog` — Heading: **"Discard unsaved changes?"**; Body: **"`<effect>` has unsaved edits. Save before `<action>`?"**; Buttons: **"Discard"** / **"Cancel"** (`FormParticleEditor.ConfirmDiscardIfDirty` verbatim shape). |
| Save As Override over an existing override file | `FormSaveConfirmDialog` — Heading: **"Override exists"**; Body: **"A loose override already exists at `<path>`. Overwrite it? The original TRE asset is never modified."**; Buttons: **"Overwrite"** / **"Cancel"**. |

## WinForms Component & Layout Contract

*(This section replaces the web "component inventory" — it is the executor's source of truth for control
selection, docking, and z-order. The interior control class choice is planner's discretion per D-06; the
invariants below are LOCKED.)*

### Two-surface structure (LOCKED, D-04)
- **`EffectsSubPanel : SubPanel`** — thin docked entry (417px). Surfaces ONLY: a Bold **"Effects"**
  banner + 2px `Colors.Secondary()` accent rule, an **"Open Effects Editor"** launch button, an
  **"Open ClientEffect Override…"** direct-open button, a `Colors.FontDisabled()` hint that TRE-sourced
  opens come from the TRE Browser, and the dimmed DEC-A3 candor footer. It adds **ZERO** format/save/reload
  logic — the Form owns all of it. Clone `TerrainSubPanel` near-verbatim (D-04).
- **`FormClientEffectEditor : UtinniForm, IEditorForm`** — the roomy host (singleton, hide-not-dispose;
  `SingletonFormClosePolicy.ShouldHideInsteadOfDispose`, mandatory from commit 1). Holds the
  toolbar + command list + field grid + status/candor strip. Clone the `FormParticleEditor` /
  `FormTerrainEditor` shell.

### Layout containers (LOCKED invariants — Pitfall 8 / `[[feedback_winforms_dockfill_zorder]]`)
- `Dock.Bottom`/`Dock.Top` strips (banner, toolbar, status + candor footer) are added **FIRST** so they
  claim their edges; the `Dock.Fill` content region (the list+grid split) stays **front-most** and never
  starves the strips (`TerrainSubPanel.BuildContent` order: footer → banner → accent → body).
- **List | field-editor split** uses a **`SplitContainer`** (the `FormParticleEditor` `mainSplit` idiom):
  set `Size` **BEFORE** `SplitterDistance` at construction, or the ctor throws and MEF silently drops
  the whole plugin. Persist `SplitterDistance` to the editor's INI section (Particle precedent).
- The whole docked-panel build runs inside the **MEF-ctor guard** (Pitfall 5/8): a throwing SubPanel
  ctor cascades the entire `IEditorPlugin` out of MEF compose with no error — wrap construction in
  try/catch and surface a read-only state label on failure (`TerrainSubPanel` `SurfaceBuildFailure`).

### Region inventory (the Form; control class is planner's per D-06)
| Region | Control choice (planner's, from precedent) | Dock / placement | State |
|--------|-------------------------------------------|------------------|-------|
| Title band | `UtinniLabel` Bold + 2px `Colors.Secondary()` accent rule | `Dock.Top` | "ClientEffect — `<name>.iff` (v`<NNNN>`)" + source (TRE vs override) |
| Toolbar | `UtinniButton` row: Open / Save▾ / Undo / Redo / **Add command** / **Remove command** / **Move up** / **Move down** / **Preview in client** | `Dock.Top` (below title) | enable-gate on a loaded doc; list-mutation buttons gate on a selected command; Save▾ gates on provenance; Preview stays enabled-with-honest-candor (see Copywriting) |
| **Command list** (flat — NO tree; CLEF has no nesting, D-06) | `ListView` (Details view: # · Tag · Summary) **or** `ThemedDataGridView` — planner's call | left split pane | one row per command in file order; reorderable via Move up/down; selecting a row binds the field grid; dirty/added rows carry the `●` accent marker |
| **Per-command field editor** | `ThemedDataGridView` (Field · Value · Type), the `FormParticleEditor` grid shape | right split pane | typed fields for the 5 known commands at the file's CLEF version (D-03); unknown command tag / unknown CLEF version → **generic raw/hex field list** in Consolas + dimmed + the LOCKED hint (NEVER a hard fail, D-06/D-13) |
| Status + candor strip | `UtinniLabel` (status) + dimmed `UtinniLabel` (reload candor) + dimmed `UtinniLabel` (DEC-A3 footer) | `Dock.Bottom` | status copy + color per tier; the honest Preview candor lands here |
| Empty-state overlay | `UtinniLabel` (centered) shown until a doc loads | over the Fill region | empty-state heading + body copy (Copywriting table) |

### Per-command typed field sets (D-03 — version-aware; from the RESEARCH CLEF field table)
The field grid renders exactly the fields the file's CLEF version defines — never more, never upgraded:
- **CPAP** (CreateAppearance): `appearanceTemplateName` (string), `timeInSeconds` (float) at v0001;
  **+** `softParticleTerminate` (bool) at v0002; **+** `minScale`/`maxScale`/`minPlaybackRate`/`maxPlaybackRate`
  (floats) at v0003. The ONLY version-variant command.
- **PSND** (PlaySound): `soundTemplateName` (string). Stable.
- **CLGT** (CreateLight): `r`/`g`/`b` (uint8), `timeInSeconds`, `constant`/`linear`/`quadratic`
  attenuation, `range` (floats). Stable.
- **CAMS** (CameraShake): `magnitude`/`frequency`/`time`/`falloffRadius` (floats). Stable.
- **FFBK** (ForceFeedback): `forceFeedbackFile` (string), `iterations` (int32), `range` (float). Stable.

String fields (`appearance` / `sound` / FF path) are the **high-value editable** refs (D-01) — these
are variable-length edits; the field editor must allow a free-text rewrite. Scalars/flags/colors are
typed-edit affordances (text/numeric cell, or a checkbox for the bool). RGB may render as three
`uint8` cells (no color-picker is required this phase; a swatch is optional polish, not contracted).

### Interaction states every region must render
- **Empty** (no effect loaded) — empty-state heading + body.
- **Loaded, no selection** — list populated, field grid shows the no-selection hint.
- **Loaded, empty command list** — the empty-command-list copy + Add command enabled.
- **Known command selected** — version-appropriate typed fields editable.
- **Unknown command tag / unknown CLEF version selected** — generic raw/hex field list, dimmed +
  Consolas + the LOCKED hint; read-only; NEVER a hard failure (D-06/D-13).
- **Dirty** — edited/added/removed/reordered → the `●` accent marker + `lblDirty` "Unsaved changes";
  Save enabled.
- **Preview** — the honest-disabled candor state this build (no live retrigger), distinct no-client vs
  no-hook copy.
- **Error** — parse/save failure → red status copy; one bad file/edit never crashes the panel or Form
  (decode exceptions caught → red status, never thrown out of a MEF ctor).

### Threading / safety (UI-relevant, LOCKED)
- Editor-local undo/redo of list mutations + field edits is **independent of the scene
  `UndoRedoManager`** (CON-M-05; `FormParticleEditor` `undoStack`/`redoStack` + `Ctrl+Z`/`Ctrl+Y`).
- Any future Preview retrigger routes through `ClientReloadDispatcher` → `GameCallbacks.AddMainLoopCall`,
  gated on `Game.IsRunning` first, **heap-free on the hot path** (the `0x0051fb0a` guard,
  `[[project_rh_snapshot_no_heap_alloc]]`, D-08) — **never** call a binding from the UI thread; **never**
  invent new reload infra. This build, the hook is unreachable, so the dispatch path is not exercised.
- The `IEditorPlugin` undo seam (`Undo`/`Redo`/`ClearUndoStack`) is **null-checked** at every call site
  (may be null until `FormMain` wires it; Pitfall 5).
- Open/parse runs on a background `Task`; UI mutations marshal back via `BeginInvoke` (no modal spinner;
  `FormParticleEditor.OpenFromLooseFile` precedent).
