<clef_spec>
<!-- The format truth (22-RESEARCH.md § CLEF Codec Spec). Container: FORM CLEF { FORM 0001|0002|0003 { N flat command chunks } }. -->
Endianness split (Pitfall 6): IFF tags + lengths are BIG-endian (IffReader handles framing);
chunk PAYLOAD scalars are LITTLE-endian. Strings are NUL-terminated C-strings (strlen+1 on disk),
NEVER length-prefixed (Pitfall 2). bool8 = 1 byte; uint8 = 1 byte; float = 4 bytes IEEE-754;
int32 = 4 bytes.

CPAP (CreateAppearance — the ONLY version-variant command), read in THIS order:
  appearanceTemplateName: C-string ; timeInSeconds: float  [v0001 ends here]
  + softParticleTerminate: bool8                            [v0002+]
  + minScale,maxScale,minPlaybackRate,maxPlaybackRate: 4 floats [v0003]
PSND (PlaySound): soundTemplateName: C-string. (stable)
CLGT (CreateLight): r,g,b: uint8 ; timeInSeconds,constantAtt,linearAtt,quadraticAtt,range: 5 floats = 23 bytes odd → no-pad quirk matters. (stable)
CAMS (CameraShake): magnitude,frequency,time,falloffRadius: 4 floats = 16 bytes. (stable)
FFBK (ForceFeedback), read in THIS order: forceFeedbackFile: C-string ; iterations: int32 ; range: float. (stable)
Unknown command tag → raw-preserve the leaf (never edited → re-emits captured slice for free).
Truncated/undecodable KNOWN command tag → per-command try/catch → raw view (IsRaw=true), NOT a hard throw (REVIEWS #4).
Trailing/residual bytes after a typed decode (cursor.Remaining != 0) → raw-fallback the command (REVIEWS #7).
Unknown version (4th+, e.g. 9999) → raw-preserve the WHOLE CLEF FORM (KnownEffectVersions = {0001,0002,0003}).
Wrong root (not FORM CLEF) / forged child count → THROW ClientEffectParseException (container framing, never degraded).
</clef_spec>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted `.iff` bytes → `ClefDecoder` / `ClientEffectCommand` | A malformed/forged/truncated ClientEffect file crosses into the variable-length field-decode path (IffPayloadCursor). Files may be hand-crafted or corrupted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-malformed | Denial of Service / Tampering | `ClefFieldCodec` / `ClientEffectCommand` variable-length decode | mitigate | Read every primitive through `IffPayloadCursor`, whose `Need()` bounds-checks each read and `ReadCString` throws `DecoderException(Truncated)` on an unterminated string — no unchecked buffer walk. A truncated/undecodable KNOWN command is CAUGHT per-command (the Particle :187-201 idiom) and degrades to a raw view (IsRaw=true), re-emitting its captured slice byte-exact — never an out-of-bounds read and never a hard abort (REVIEWS #4). Covered by `ClefTruncatedKnown` + `ClefRawFallback`. |
| T-22-residual | Tampering | typed command decode leaving slack bytes | mitigate | After a typed decode the cursor must have `Remaining == 0`; a command with residual/trailing bytes degrades to a raw view rather than silently dropping or rewriting slack on a later edit (REVIEWS #7). Covered by `ClefCanonicalPayload`. |
| T-22-version-upgrade | Tampering | CPAP encoder emitting fields above the source version | mitigate | The CPAP encoder THROWS `ClientEffectParseException(VersionFieldMismatch)` when a v0003-only (or v0002) field is supplied below that version — the D-03 encode-boundary guard prevents a v0001 file silently gaining v0003 bytes (REVIEWS HIGH #2). Covered by `ClefEncodeVersionGuard`. |
| T-22-forged-count | Denial of Service | `MutableClientEffect.FromMutableIff` flat command loop | mitigate | Enforce the `MaxNodeCount` cap (cloned from `MutableParticleEffect`, T-15-02) before allocating the command list; reject a forged child count. `IffReader`'s existing 64MB chunk cap bounds the outer parse. CONTAINER framing throws — only command-leaf payloads degrade (REVIEWS #4). |
| T-22-version-abort | Denial of Service | unknown CLEF version / unknown command tag | mitigate | Raw-fallback is the contract (D-13): an unknown version raw-preserves the whole CLEF FORM, an unknown command tag raw-preserves the leaf — neither throws. A malformed file degrades, never hard-aborts the future MEF-hosted editor. Covered by `ClefRawFallback`. |

(Path-containment and save-target threats are out of this plan's scope — the codec writes no files. They are modeled in 22-02 / 22-04.)
</threat_model>
