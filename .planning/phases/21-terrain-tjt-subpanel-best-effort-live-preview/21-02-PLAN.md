<objective>
Build the roomy `FormTerrainEditor` child Form — the heavy tree+field-editor surface — that the thin
docked SubPanel (Plan 03) launches. It opens a `.trn`, renders the navigable TGEN layer tree + read-only
palettes, shows typed fields for Tier-1 tags and a read-only generic field list for everything else
(never a hard fail), edits fixed-length leaves + active-flag toggles, saves byte-exact via the Plan 01
in-proc save target, and fires the live preview on both Save and an explicit manual Preview through the
EXISTING reload dispatcher with honest tiered candor.

The D-02 escape hatch is to host the heavy editor in a launched roomy surface. This plan builds that host.

Output: `FormTerrainEditor.cs` (+ Designer) — the consuming UI for the Phase 20 model and the Plan 01
save/candor helpers, with ZERO new format/reload logic.
</objective>

  `--field active` mutates. The active-flag toggle resolves the IHDR DATA leaf's stable id by calling the
  net-new Plan 01 helper `TerrainSaveTargets.ResolveIhdrLeafStableId(doc.Mutable, layer.StableIdPath)`,
  then passes that leaf id (`tag=IHDR`, the synthetic active version, `field=active`) to `SaveLooseOverride`.
  The UI never walks the tree for the IHDR leaf itself and never reuses the private CLI walk.
</planner_decisions>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user `.trn` bytes → codec | Opened payload parsed by the Phase 20 codec (consumed as-is). |
| field edit → loose-override write | The edit + relative asset path crosses into a filesystem write under the client root (via Plan 01 save target). |
| UI thread → game thread | Reload binding crosses the UI→game-thread boundary (via the existing dispatcher only). |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-save-containment | Tampering | FormTerrainEditor save → `TerrainSaveTargets` | mitigate | Delegates to the Plan 01 in-proc target which enforces `LooseOverridePath.Resolve` fail-closed `--root`; a path-escape returns red "Save failed: <reason>", never writes. |
| T-21-thread | Denial of Service / crash | reload dispatch from the UI thread | mitigate | All reload goes through `ClientReloadDispatcher.Dispatch` (wraps `AddMainLoopCall`, `Game.IsRunning`-gated); never a direct binding call; exactly one `Action` per save/preview (D-06, the `0x0051fb0a` guard). |
