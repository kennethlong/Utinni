# Phase 21 — UI Design Contract

> Visual and interaction contract for the **Terrain TJT SubPanel** (+ best-effort live preview).
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Platform reality (read first):** This is NOT a web/mobile frontend. The deliverable is a
> **.NET Framework (net4.7.2) WinForms** docked `SubPanel` (`IEditorPlugin`) inside **The Jawa
> Toolbox** — an injected SWG modding tool. There is no HTML/CSS, no component library, no browser,
> no design-token JSON. Every dimension below is mapped to WinForms control selection, layout
> containers (SplitContainer/TreeView/PropertyGrid/Panel docking), dock/z-order rules, state/feedback
> copy, and consistency with the **existing TJT editor visual conventions** (`Colors` dark theme,
> 8.25pt base font, 4px-grid spacing, `IffChunkTree`/`TreDetailPane`/`SnapshotPanel` precedents).
> The "color" / "typography" / "spacing" sections are filled against the established TJT theme — they
> are house-style **conformance constraints**, not a new palette to invent.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (WinForms desktop; shadcn N/A — not a React/Next/Vite project) |
| Preset | not applicable |
| Component library | none — System.Windows.Forms + existing TJT shared controls (`UtinniLabel`, `UtinniButton`, `UtinniContextMenuStrip`, `IffChunkTree`, `TreDetailPane`) under `UtinniCoreDotNet.UI.*` |
| Icon library | none — text labels + glyph chars only (matches the IFF-editor `●`/`＋` precedent); no icon font |
| Font | Segoe UI 8.25pt (the WinForms `Form.Font` default TJT inherits); `Consolas` 9pt is the monospace exception for hex/raw-byte regions only |

**Form factor (LOCKED, CONTEXT D-01):** a docked `TerrainSubPanel : SubPanel` registered via
`IEditorPlugin.GetSubPanels()` — matching `SnapshotPanel`/`ScenePanel`, **not** a `Form`. Where the
heavy tree+field-editor surface physically lives (in-panel vs a roomier `GetStandalonePanels()` child
launched from the panel) is **planner's call** (D-02); the invariants in this contract hold for either.

**Theme source of truth:** `UtinniCoreDotNet.UI.Theme.Colors` (dark theme active). Do NOT hard-code
colors — call `Colors.Primary()` / `Colors.PrimaryHighlight()` / `Colors.Secondary()` / `Colors.Font()`
/ `Colors.FontDisabled()` so a theme flip stays centralized (TreDetailPane precedent).

## Spacing Scale

WinForms is pixel-positioned; TJT panels lay out on a **4px base grid** (see `TreDetailPane` row pitch
16, splitter width 4, padding 8). Multiples of 4 only.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Control inset, splitter width (`SplitterWidth = 4`), accent-rule height, grid base unit |
| sm | 8px | Compact control gap, `Panel.Padding = 8` (info-panel precedent) |
| md | 16px | Default label-row pitch (metadata strip rows at 16px), control-group vertical gap |
| lg | 24px | Section heading band height region / labeled-group separation |
| xl | 32px | Major sub-section break inside a tall panel |
| 2xl | 48px | (reserved — rarely needed in a docked panel) |
| 3xl | 64px | (reserved — rarely needed in a docked panel) |

**Exceptions:**
- Status/badge label rows and section-title labels use **18px** height (TreDetailPane `lblStructuredTitle`/`lblHexHeader` precedent) — an 8.25pt line needs ~18px; treat 18 as the established text-row exception, not a new grid value.
- `SplitContainer.Panel1MinSize` / `Panel2MinSize` follow TreDetailPane (40px tree min, 80px content min) — collapse-guard minimums, not layout spacing.
- Touch-target sizing does not apply (mouse-only desktop tool).

## Typography

WinForms `Font` objects, not CSS. The TJT house rule (TreDetailPane lines 609, 705, 767): **base
8.25pt regular for everything; Bold is reserved**, color/position differentiates roles instead of
weight. Exactly the constrained set below.

| Role | Size | Weight | Notes |
|------|------|--------|-------|
| Body / field value | 8.25pt | Regular | Tree node text, field labels, field values, status copy. The default `Form.Font`. |
| Banner / section title | 8.25pt | **Bold** | The ONE authorized Bold use — the panel/section header banner (e.g. "Terrain — `<planet>.trn`"), differentiated further by the 2px `Colors.Secondary()` accent rule above it (UtinniForm/TreDetailPane precedent). |
| Disabled / hint label | 8.25pt | Regular | Key labels, hint text, reload-candor footer — rendered in `Colors.FontDisabled()`, not a different size. |
| Monospace (raw bytes) | 9pt `Consolas` | Regular | Raw-fallback hex peek + any byte-offset readout only (the documented monospace exception). |

Line height: WinForms auto-manages line metrics; no ratio token. Multi-line copy uses `AutoSize=false`
fixed-height labels/panels (TreDetailPane convention) so the dock layout stays stable.

**Hard rule:** no third font family, no italics, no size beyond {8.25pt, 9pt-Consolas}. Bold only on
the banner/section title.

## Color

The TJT dark theme is a fixed 3-role palette from `Colors`. Map directly to the 60/30/10 model — these
are **conformance values**, sourced from `Colors.*`, never new hexes.

| Role | Value | Source | Usage |
|------|-------|--------|-------|
| Dominant (~60%) | `#282828` (40,40,40) | `Colors.Primary()` | Panel background, all surface fills |
| Dominant variant | `#404040` (64,64,64) | `Colors.PrimaryHighlight()` | Tree / list / field-input control backgrounds (the inset content wells) |
| Dominant shadow | `#191919` (25,25,25) | `Colors.PrimaryShadow()` | Column-header band, recessed strips |
| Secondary text (~30%) | `WhiteSmoke` / `#646464` | `Colors.Font()` / `Colors.FontDisabled()` | Primary text in WhiteSmoke; keys/hints/disabled in FontDisabled gray |
| Accent (~10%) | `#007ACC` (0,122,204) | `Colors.Secondary()` | RESERVED — see list below |
| Destructive / error | `Color.Red` | `System.Drawing.Color.Red` | Error-state status text ONLY (TreDetailPane/FormIffEditor precedent: red `lblStatus`/info-heading on failure) |

**Accent (`Colors.Secondary()` #007ACC) reserved EXCLUSIVELY for:**
1. The 2px accent rule above the panel/section banner.
2. Dirty/added-node decoration on the layer tree (the `●` dirty / glyph accent — mirrors the IFF-editor `●`/`＋` convention; node text tinted `Colors.Secondary()` when its leaf has an unsaved edit).
3. The active splitter grip / focused-control affordance already themed by the shared controls.

Accent is **never** used for "all buttons," general selected-row highlight (that uses the control's
native themed selection), or decorative emphasis. Edits are signaled by the dirty `●` glyph, not by
recoloring whole controls.

**Live-preview / reload tier is signaled by COPY + a neutral/gray/red color, never a green "success"
hue** — there is no green token in the theme, and D-07 forbids over-promising. Reloaded / pending tiers
use `Colors.Font()` (neutral); only the no-client / error tier uses `Color.Red` (FormIffEditor
`OnReloadClicked` precedent, verbatim).

## Copywriting Contract

All copy is desktop micro-copy on labels, buttons, tooltips, and confirm dialogs. The **reload-candor
tiers are LOCKED vocabulary** carried over verbatim from the shipped editors (FormIffEditor /
FormParticleEditor) and `ClientReloadDispatcher` — do NOT soften or invent new wording (D-05/D-07).

| Element | Copy |
|---------|------|
| Primary action (commit to disk) | Button label **"Save"** (writes the loose-override `.trn` via the Phase 20 `apply-save-trn` field-aware path). When opened read-only from the TRE Browser, the first commit is **"Save As Override…"** (writes a new loose override; TREs are never edited in place — D-08). |
| Secondary action (iterate without disk) | Button label **"Preview"** — applies the pending edit to the live client without committing to disk (D-04), held to the same heap-free dispatch contract (D-06). |
| Open entry (from TRE Browser) | Context action **"Open in Terrain Editor"** on a `.trn` TRE entry → opens read-only. |
| Open entry (loose override) | **"Open Terrain Override…"** file picker for an existing loose-override `.trn`. |
| Empty state heading | **"No terrain loaded"** |
| Empty state body | **"Open a planet's .trn from the TRE Browser, or open an existing loose override, to edit its procedural layers."** |
| No-selection (tree shown, no node picked) | **"Select a layer, boundary, filter, or affector to view its fields."** (mirrors TreDetailPane `ShowEmpty` body) |
| Read-only palette banner | **"Shared palette (read-only)"** — shown on each of the six palette nodes; family entries display `familyId → name` and are non-editable. |
| Name-field disabled hint (Phase 20 D-06 deferred) | **"Name editing isn't supported yet — names are shown read-only."** (name fields render disabled, never editable this phase) |
| Raw-fallback field hint | **"This tag isn't typed yet — its original bytes are preserved exactly and saved unchanged."** (verbatim from FormParticleEditor `RawFieldHint`; degrade-not-fail per D-03 / Phase 20 D-01/D-02) |
| Obsolete-tag note (Phase 20 D-03) | **"Obsolete tag — recognized, ignored, and re-emitted unchanged. Not editable."** |
| **Reload tier — live (`ReloadedTerrain`)** | Status **"Reloaded (terrain)"** in `Colors.Font()`. *(Subject to D-07: if the maintainer live-smoke shows ReloadTerrain does NOT visibly re-read procedural edits in-session, this build ships the `PendingNextSceneChange` copy instead — do NOT label it "live" until observed.)* |
| **Reload tier — pending (`PendingNextSceneChange`)** | Status **"Reloads on next scene change"** in `Colors.Font()`. Tooltip: **"Reloads on next scene change. Procedural terrain is cached by the running scene — trigger a scene change via TJT's chat-command load to refresh it."** |
| **Reload tier — no client (`Unavailable`)** | Status **"No live client — start SWG to preview terrain edits in-session."** in `Color.Red`. |
| Preview disabled (running, hook unreachable) | Tooltip **"Live terrain preview isn't wired this build — edits show on the next scene change or relog."** (FormParticleEditor `PreviewNoHookTooltip` shape) |
| Save-before-preview guard | **"Nothing to preview — edit a field first."** / for the on-save path: **"Save first — Preview uses the last edit to classify the reload."** (FormIffEditor guard precedent) |
| Save success | Status **"Saved → `<override-path>`"** in `Colors.Font()`. |
| Save failure / path-escape | Status **"Save failed: `<reason>`"** in `Color.Red` (e.g. `--root` containment rejection from Phase 20 D-07). |
| DEC-A3 preview-scope footer (dimmed) | **"Preview is live in the real SWG client — Utinni never renders terrain itself."** (verbatim DEC-A3 candor; dimmed `Colors.FontDisabled()` footer, FormSnapshotPlacements precedent) |

**Destructive actions:** This phase has **no inherently destructive action** — edits are
fixed-length, byte-exact, undoable via the editor-undo seam, and saves write to a *loose override*
(the source TRE is never mutated; D-08). The only overwrite case:

| Action | Confirmation |
|--------|-------------|
| Save As Override over an existing override file | Confirm dialog — Title: **"Override exists"**; Body: **"A loose override already exists at `<path>`. Overwrite it? The original TRE asset is never modified."**; Buttons: **"Overwrite"** / **"Cancel"**. |

## WinForms Component & Layout Contract

*(This section replaces the web "component inventory" — it is the executor's source of truth for
control selection, docking, and z-order. Control class and in-panel-vs-standalone split are
planner's discretion per D-02/D-03; the invariants below are LOCKED.)*

### Layout containers (LOCKED invariants — Pitfall 8)
- The panel's `Dock.Fill` content region is added **FIRST** (front-most) so docked `Top`/`Bottom`
  strips (banner, action bar, status/candor footer) claim their edges and the Fill region never
  starves them (`[[feedback_winforms_dockfill_zorder]]`, TreDetailPane `BuildContentArea` precedent).
- Tree | field-editor split uses a **nested `SplitContainer`**; set `Size` BEFORE `SplitterDistance`
  at construction or the ctor throws and MEF silently drops the whole plugin (TreDetailPane lines
  717–743; CONTEXT D-02). Use `Panel1MinSize`/`Panel2MinSize` collapse guards (40/80 precedent).
- The whole panel build runs inside the **MEF-ctor guard** (D-09): a throwing ctor makes the
  `IEditorPlugin` vanish from compose with no error — wrap construction so a partial-load surfaces a
  state panel, never an exception.

### Region inventory (logical — applies to in-panel OR hosted-standalone)
| Region | Control choice (planner's, from precedent) | Dock / placement | State |
|--------|-------------------------------------------|------------------|-------|
| Banner | `UtinniLabel` Bold + 2px `Colors.Secondary()` accent rule | `Dock.Top` | "Terrain — `<planet>.trn`" / source (TRE vs override) |
| Action bar | `UtinniButton` row: Open / Save (or Save As Override) / Preview | `Dock.Top` (below banner) | buttons enable-gate on load + `Game.IsRunning` (SnapshotPanel `UpdateSceneAvailability` precedent) |
| Layer tree | `IffChunkTree`-style `TreeView` **or** custom — planner's call (D-03) | left split panel | TGEN → Layers → Boundaries/Filters/Affectors/sub-layers; node label shows name + active-flag state; dirty leaves tinted `Colors.Secondary()` |
| Field editor | stock `PropertyGrid` (free categorization) **or** `TreDetailPane`-style custom pane — planner's call (D-03) | right split panel | typed fields for Tier-1 tags; **generic field list** for unknown/long-tail (never hard-fail); names + palettes **read-only/disabled** |
| Status + candor footer | `UtinniLabel` (status) + dimmed `UtinniLabel` (DEC-A3 footer) | `Dock.Bottom` | reload-tier copy (table above), color per tier |

### Interaction states every region must render
- **Empty** (no terrain loaded) — empty-state heading + body copy (Copywriting table).
- **Loaded, no selection** — tree populated, field editor shows the no-selection hint.
- **Typed leaf selected** — typed fields editable (fixed-length scalar/enum + active-flag toggle only).
- **Raw-fallback / obsolete / palette / name selected** — generic field list / read-only, with the matching hint copy; NEVER a hard failure (Phase 20 D-01/D-02/D-03).
- **Dirty** — edited leaves carry the `●` glyph + `Colors.Secondary()` tint; Save enabled.
- **Reload tiers** — the three LOCKED candor states (live / pending / no-client) on the status footer.
- **Error** — parse/save failure → red status copy; one bad file/edit never crashes the panel.

### Threading / safety (UI-relevant, LOCKED)
- Every native reload call routes through `ClientReloadDispatcher.Dispatch` → `GameCallbacks.AddMainLoopCall` → `GroundScene.Get().ReloadTerrain()` (INSTANCE thiscall) — **never** call a binding from the UI thread; **never** invent new reload infra (D-05).
- Preview/regen dispatch is **heap-free, push-on-edit** (stack snapshot), never per-frame — the `0x0051fb0a` crash guard (D-06 / `[[project_rh_snapshot_no_heap_alloc]]`).
- Undo seam (`AddUndoCommand`/`Undo`/`Redo`/`ClearUndoStack`) is **null-checked** at every call site (may be null until `FormMain` wires it; D-09).
