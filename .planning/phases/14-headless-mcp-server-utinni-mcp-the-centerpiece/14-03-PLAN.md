<objective>
Build the write surface: 4 `save_*` tools (`save_iff`, `save_datatable`, `save_stringtable`, `save_object_template`), the distinct off-by-default `repack_tre` destructive tool, and the `roundtrip_check` verify-only tool. Each `save_*` tool is a THIN dispatcher over the SINGLE Plan-14-03a `apply-save-*` CLI verb — one `Process.Start`, envelope passed through OPAQUELY, persist-vs-fail decided on the CLI EXIT CODE. Delivers MCP-02's write half. Zero format/business logic; no domain-field parsing.

Purpose: The edit->save half of the centerpiece. The cross-AI review (BLOCKING) proved the old `roundtrip->save` two-step never persisted the edit AND forced the host to parse `bytesEqualUntouched`. Plan 14-03a fixed that with single atomic `apply-save-*` verbs (apply+verify+commit, failed-verify=exit 2). This plan's `save_*` tools simply wrap each verb 1:1 and hand the mapper the result — the host never interprets a domain field; the exit code carries the decision.
Output: 4 save tools (each -> one apply-save-* verb) + repack_tre + roundtrip_check + a verb-name helper, unit-tested for the dispatch + the MCP-boundary path-escape.
