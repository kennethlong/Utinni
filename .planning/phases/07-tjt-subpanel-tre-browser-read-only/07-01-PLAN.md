## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk `.tre`/`.toc` file → TreFile/CotMasterIndex parser | Untrusted attacker-influenceable binary (a mod file a user downloaded). All header counts, offsets, sizes, and compressed blocks are adversary-controlled. |
| CLI `parse-tre` argv → TreFile.Open | User-supplied path; existing FileNotFound (exit 3) + exception envelope (exit 2) contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Denial of Service | TreFile/CotMasterIndex header count×stride allocation | mitigate | ValidateLength caps every count/size against stream length + 256 MB MaxBlockSize before allocation; expectedInfoUncompressedSize = recordCount × stride is bounds-checked (existing pattern extended to v6000 32-byte stride + COT2000 blocks). |
| T-07-02 | Denial of Service | zlib/deflate inflate (decompression bomb) | mitigate | Inflate output capped at min(256 MB, declared uncompressed size); over-expansion throws DeflateExpansionExceedsCap (existing GetRecordData/ReadBlock cap pattern reused for zlib path). |
| T-07-03 | Tampering | out-of-bounds offsets (infoOffset, nameOffset, fileNameOffset, treeFileIndex, per-record offset) | mitigate | Every offset bounds-checked against stream length and its containing block before use; `treeFileIndex < numTreeFiles` validated; cumulative name offsets validated against name-block length. |
| T-07-04 | Denial of Service | truncated / malformed archive | mitigate | Short-read detection (existing Truncated kind) on every block read; structural validation before decode; zlib header validated (`%31==0`) before stripping. |
| T-07-05 | Tampering | path-traversal via crafted virtual path (`../`) | mitigate | Phase 7 read-only: paths are surfaced as data only, never resolved against the filesystem; no extraction in V1. CotMasterIndex stores Path as an opaque string. |
| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan (RESEARCH Package Legitimacy Audit: BCL + in-repo only); nothing to slopcheck. |
</threat_model>
