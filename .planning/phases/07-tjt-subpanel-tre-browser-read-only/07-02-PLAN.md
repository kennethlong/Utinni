## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk `.tre`/COT2000 index → CotMasterIndex/TreFile (consumed by the Form) | Untrusted binary; all bounds-checking is enforced in the plan-01 framework core the Form consumes (no parsing logic added in the UI layer). |
| live `Game.Repository` (in-process) → Form overlay read | In-process trusted data harvested by the native detour; read-only consumption, no native modification (CON-N-02). |

| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs (BCL + in-repo controls only; RESEARCH Package Legitimacy Audit). |
