<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| on-demand payload bytes → IffReader.Read(Stream) | Untrusted IFF binary from a .tre archive; bounds-checking + 64 MB cap enforced inside the shared Formats/Iff reader (no parsing added in the UI). |
| decoded payload → detail-pane rendering | A pathological chunk tree could nest deeply; the IFF reader's NestedChunkOverflow + cap handle depth/size; the UI renders the bounded output only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-09 | Denial of Service | pathological IFF nesting / huge chunk in the selected payload | mitigate | IffReader enforces 64 MB MaxChunkSize + NestedChunkOverflow + Truncated checks (existing); the detail pane consumes the bounded parse output only and wraps the parse in try/catch → ShowParseFailure rather than crashing. |
| T-07-10 | Denial of Service | large readable payload freezing the UI thread | mitigate | On-demand read + decode runs on a background Task, marshaled via Control.Invoke; metadata shows immediately, content shows "Decoding…" until ready. |
| T-07-11 | Tampering | a corrupt TOC entry / truncated payload | mitigate | TreParseException / IOException from GetRecordData caught and routed to ShowParseFailure; one bad file never takes down the browser (UI-SPEC States). |
| T-07-12 | Information Disclosure | clipboard "Copy path/CRC" | accept | Read-only clipboard copy of displayed text; no asset write/export; benign for a local desktop tool. |
| T-07-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs (BCL + in-repo only; RESEARCH Package Legitimacy Audit). |
</threat_model>
