  parse-tre          Parse a .tre archive and emit sorted-key JSON to stdout.

  list-objects       List world-snapshot objects from a ws.iff via the TRE
                     reader.

  inspect-iff        Emit the chunk tree of an IFF file as JSON.

  decode-iff         Decode a typed IFF asset (datatable / string-table /
                     object-template) to JSON.

  roundtrip-iff      Parse -> [optional mutate-leaf | remove-leaf] -> serialize
                     -> re-parse an IFF; assert byte-exact untouched chunks.

  roundtrip-tab      Parse -> optional mutate -> serialize -> re-parse a .tab;
                     assert byte-exact identity on untouched cells.

  validate-plugin    Reflect on a plugin directory and report compliance.
                     WARNING: Loads each .dll under the given directory; only
                     run against trusted plugin directories. PluginLoader
                     composition + managed-DLL inspection execute static
                     initialisers as a side effect.

  help               Display more information on a specific command.

  version            Display version information.
